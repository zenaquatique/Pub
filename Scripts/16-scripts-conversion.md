## RÈGLES DU HOOK (à mémoriser)

1. **Chiffre précis** > vague ("15€" > "pas cher")
2. **Contradiction** > confirmation ("tu dépenses 15€ pour 3 plantes" crée une tension)
3. **"Tu"** dans le hook quand c'est possible — le spectateur se sent concerné
4. **Jamais de question rhétorique faible** ("Tu connais les boutures ?") — affirme ou provoque
5. **Le visuel doit renforcer le hook** — si le texte dit "arnaque", l'image doit montrer ce qui arnaque
6. **Premiere syllabe en bouche** — pas de plosives sur micro (évite "p" "b" en attaque directe)
