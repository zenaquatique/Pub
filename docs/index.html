Configuration requise

Cette appli a besoin d'un projet Supabase (gratuit) pour synchroniser tes tâches entre appareils.

Ouvre docs/js/config.js, remplace SUPABASE_URL et SUPABASE_ANON_KEY par les valeurs de ton projet Supabase, puis recharge cette page. Toutes les étapes détaillées sont dans docs/README.md.
