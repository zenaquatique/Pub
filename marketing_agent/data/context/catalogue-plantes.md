## Plantes pour débutants (no-fail)
- Anubias nana ou barteri
- Java Fern (Microsorum pteropus)
- Cryptocoryne wendtii
- Vallisneria spiralis
- Hygrophila polysperma
- Sagittaria subulata
- Java Moss

## Plantes bac low-tech (sans CO2 injecté)
- Anubias, Java Fern, Cryptocoryne, Vallisneria, Sagittaria
- Mousses en général
- Limnobium, Salvinia (flottantes)
- Hygrophila, Bacopa (tiges faciles)

## Plantes aquascape avancé (nécessitent CO2 + lumière forte)
- HC Cuba, Monte Carlo, Glossostigma (tapis)
- Rotala macrandra, Rotala Laos
- Eriocaulon, Pogostemon stellatus
- HM (Hemianthus micranthemoides)
